The boundary files in this folder are derived from geoBoundaries gbOpen datasets released under the
Open Data Commons Open Database License (ODbL) 1.0 (https://opendatacommons.org/licenses/odbl/1-0/).
They have been simplified, clipped to 10-degree tiles and repacked for this project. This derived
database is offered under ODbL 1.0.

Contains information from OpenStreetMap, (c) OpenStreetMap contributors
(https://www.openstreetmap.org/copyright).

Sources: the original source of each country is listed in frontend/assets/geography/index.json
("countries", "adm2", "source" and "licence_source"). geoBoundaries: Runfola, D. et al. (2020)
geoBoundaries: A global database of political administrative boundaries. PLoS ONE 15(4): e0231866.

The rest of this project is not covered by this licence. Map context only: these lines are never used
in any fire value.
